# IR Analysis Scripts

This directory contains Python scripts used to analyze and validate the `ir.json` file generated by the IR tracing tool.

The scripts help verify the correctness of the dataset and extract useful information about how nodes evolve during JIT compilation.

---

# Files

## group_nodes_by_phase.py

### Purpose

This script parses the `ir.json` file and **groups nodes by the compiler phase in which they were created**.

Each node contains an `instAccess` log that records instructions interacting with the node.  
A node creation event is represented by an access entry with:

```
type = 7  (CREATE)
```

Each access entry also records a `PhaseFnId`, which identifies the compiler phase responsible for the operation.

The script finds the `CREATE` event for each node and groups nodes based on its `PhaseFnId`.

The phase name is resolved using the `fnId2Name` mapping in the JSON file.

### Output

The script prints groups in the following format:

```
PhaseName: [node_id_1, node_id_2, node_id_3]
```

Example:

```
v8::internal::compiler::GraphBuilderPhase::Run: [1, 2, 3, 4]
v8::internal::compiler::InliningPhase::Run: [5, 6]
```

### Usage

```
python3 group_nodes_by_phase.py ir.json
```

### Checks Performed

The script performs several consistency checks:

- Every node must contain an `instAccess` log.
- Every node must contain a `CREATE` event (`type = 7`).
- Every `CREATE` event must contain a valid `PhaseFnId`.

If any of these conditions fail, the script terminates with an error.

---

## validate_phase_ids.py

### Purpose

This script validates that all `PhaseFnId` values recorded in `instAccess` entries are valid.

A `PhaseFnId` is considered valid if it appears in the `fnId2Name` mapping stored in the JSON file.

This script ensures that all phase references recorded during tracing correspond to known compiler phases.

### Output

If all entries are valid:

```
All PhaseFnId values are valid.
```

If invalid entries are found, the script reports them:

```
Invalid PhaseFnId entries detected:

Node 42, inst 10321: invalid PhaseFnId 999999
Node 57, inst 10345: missing PhaseFnId

Total errors: 2
```

### Usage

```
python3 validate_phase_ids.py ir.json
```

# Requirements

These scripts require:

# Notes

- The scripts assume that `ir.json` follows the schema documented in the repository.
- Instruction IDs inside `instAccess` are stored as strings in JSON and are converted to integers during processing.
- These tools are intended for **dataset validation and IR evolution analysis** during JIT compilation research.
